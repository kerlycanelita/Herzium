# Herzium 1.10.3

Separate Fabric builds for Minecraft **1.21.10, 1.21.11, 26.1, 26.1.1, 26.1.2,
26.2 and 26.3**. Choose the JAR matching your exact game version.

- **Herzium (last input)** is the default selection order. Vanilla and Vanilla
  reversed remain available in Mod Menu. Alternate orders change the real
  selected slot and are visible to servers; existing configurations retain
  their saved choice.
- Faster hotbar previews and ordinary-item equip visuals, with normal
  combat-item transitions. Attack/Use dispatch, cooldowns and input sampling
  retain their normal paths.
- Shared lifecycle and action-boundary fixes across the 1.21.x and 26.x builds.
- Correct screen and hotbar hooks on 26.2. A dedicated hand-state extraction
  adapter supports Minecraft 26.3's rendering changes.

Requires **Fabric Loader 0.19.3+**. Minecraft 1.21.x uses **Java 21**; Minecraft
26.x uses **Java 25**. Install **Fabric API** for localized mod text and
**Mod Menu** to access the settings button. Client-side only.

See the [release audit](../audits/AUDIT-1.10.3-release-2026-09-22.md) for exact
verification coverage and remaining compatibility limits.
